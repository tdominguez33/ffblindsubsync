Reference Mode Chooses how speech is detected in the reference video. Embedded Subs tries built-in subtitles first and falls back to Audio VAD; higher KHz is more accurate, lower KHz is faster.
Mid-file breaks Handles sudden timing jumps mid-video (e.g. cut ads or extra scenes). Auto-detect fixes clear breaks safely, Off uses a single global offset, and Aggressive searches harder for splits.
Only shifts subtitles by a constant offset without stretching or compressing their speed to fix FPS mismatches (e.g. 23.976 vs 25 fps).
Searches continuously for the exact optimal framerate ratio between video and subtitles instead of testing only standard FPS pairs. Slower, but helpful for unusual speed drift.
